<ins>binclock - re-designed Binary Clock using modern techniques</ins>

The original binclock utility was written very early in my Windows development history,
and used many archaic elements.  This version will utilize all the elements that I know about now.
These will include:

- incorporate der_libs
- use ini file vs registry for storing data
- use resource file for menus and dialog boxes
