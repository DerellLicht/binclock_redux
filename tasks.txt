These are 2 separate things, and most likely you can make the class movable.

You can't copy it because of course then there wouldn't be a unique pointer with just 1 owner.

other notes:
C++17
❝A non-template constructor for class X is a move constructor if its first parameter is of 
type X&&, const X&&, volatile X&&, or const volatile X&&, and either 
there are no other parameters or else all other parameters have default arguments (11.3.6).❞
